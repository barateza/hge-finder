🔧 WHAT'S READY TO USE
═══════════════════════════════════════════════════════════════════════════════

Import & Use:

  from src.notifications import Alert, NotificationManager
  
  # Create manager with Discord
  manager = NotificationManager(
      discord_webhook="https://...",
      alert_config=Alert(max_distance_ly=50, max_age_hours=24)
  )
  
  # Send notifications on new signal
  notification = manager.check_and_notify(signal, location)

Configuration (in .env):

  DISCORD_WEBHOOK_URL=https://discordapp.com/api/webhooks/ID/TOKEN
  ALERT_DISTANCE_LY=50
  ALERT_MAX_AGE_HOURS=24
  ENABLE_DISCORD_ALERTS=true
  NOTIFICATION_COOLDOWN_SECONDS=60

Discord Alert Format:

  Title:       🎯 NEW HGE SIGNAL DETECTED
  System:      Shinrarta Dezhra
  Distance:    35.28 ly
  Signal Age:  2m ago
  Coordinates: (55.72, -49.50, 17.40)
